# Pet-Hub

Sistema SaaS para clínicas veterinárias e pet shops.

## Estrutura do projeto

```txt
backend/   -> API Spring Boot
frontend/  -> Aplicação React
```

## Stack

### Backend
- Java 21
- Spring Boot
- PostgreSQL

### Frontend
- React
- Vite
- TypeScript

## Objetivo

Centralizar:
- cadastro de clientes
- cadastro de pets
- consultas
- prontuários
- agenda veterinária
- financeiro

## Status

Projeto em desenvolvimento.
